# FreshMate Q版智慧冰箱 Demo（日期篩選／分類／小數庫存版）

直接以瀏覽器或 VS Code Live Server 開啟 `index.html`。保留原有食譜教學、料理扣庫存、賣場示範比價及依庫存動態顯示食材篩選選項。

新增功能：到期提醒切換 1／3／5 天（不含已過期食材）；我的冰箱依狀態、類別、購買日期、有效日期、開封日期排序；食材數量可填 0.5 盒、150 克等；食材類別可複選。日期排序中，購買／開封日期採新到舊，有效日期採近到遠。類別排序以第一個類別為準。食譜的盒、克不能直接互換，僅自動換算公斤／克及公升／毫升。

資料存在瀏覽器 localStorage；本專案的賣場價格是模擬值，並非即時報價。
